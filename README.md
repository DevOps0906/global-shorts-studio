# 글로벌쇼츠 스튜디오 (global-shorts-studio)

떡상 소재를 **찾고(레이더)** → 원본 하나로 한국어·일본어 쇼츠를 **만들고(스튜디오)** → 내 채널에 **올리고** → 성과를 **재는** 쇼츠 제작 SaaS. 브랜드: NOMAD AI Factory / 디지털노마드연구소.

## 현재 상태

기획과 디자인 시안 단계다. 앱 코드는 아직 없다.

| 경로 | 내용 |
| --- | --- |
| [`docs/PLAN.md`](docs/PLAN.md) | 통합 기획서(요약, 강의 정리, 미호메이트 분석, 화면 명세, AI 파이프라인, 데이터 모델, 정책 리스크, 수익화, 구현 계획) |
| `design/prototypes/` | 디자인 시안 9화면: 홈, 편집, 레이더, 저장 채널, 관리, 마이페이지, 설정, 고객문의, 로그인 |
| `design/tokens.css` | 시안과 같은 색·글자 크기·반응형 구간 토큰 |
| `supabase/migrations/0001_studio_schema.sql` | DB 스키마 초안(RLS 포함, 적용 전 검토) |

## 기술 스택(예정)

Next.js(App Router) · TypeScript · Tailwind · shadcn/ui · Supabase · FFmpeg/Remotion · YouTube Data API v3

## 로드맵

1주 앱 뼈대·로그인 → 2주 레이더·저장 채널 → 3주 스튜디오 분석·제목/대본 → 4주 편집·내보내기·크레딧. 자세한 내용은 기획서 12장.

## 주의

해외 영상을 재가공하는 제품이라 유튜브 재사용 콘텐츠 정책이 가장 큰 리스크다. 권리 확인 체크, 변형도 점수, 반복 원본 경고를 제품에 넣는 이유는 기획서 7장에 있다.
